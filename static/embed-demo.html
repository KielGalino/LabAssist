Widget embedding demo

This plain page stands in for any other website (for example a lab or class portal). It contains no helpdesk code except one line:

<script src="http://localhost:8000/static/embed.js"></script>

Click Lab Helpdesk in the bottom-right corner to open LabAssist. The widget talks to the same backend as the main app, so the same guardrails, rate limits and tickets apply.

A fuller example, a sample CSIS ICT Laboratory portal page, is at /portal.
