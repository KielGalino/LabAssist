# SOP-04: Slow or Frozen Thin Client

**Applies to:** Thin client sessions on the MultiPoint servers.
**Common phrases:** slow computer, lagging, frozen screen, not responding, hang, mouse stuck, mabagal ang PC, ang bagal, nag-hang, nagha-hang, nag-freeze, hindi gumagalaw

## Free up your session
1. Close programs you are not using (especially browsers with many tabs and videos).
2. Press `Ctrl + Shift + Esc` to open Task Manager and end any program marked "Not responding".
3. Save your work often (see SOP-08).

## If the screen is frozen
1. Wait 1 minute - the server may be busy.
2. Ask your teacher to restart your session from MultiPoint Dashboard.
3. The teacher logs the station in again; files saved in the shared folder are kept (SOP-08).
4. Do not try to sign out and log in yourself - students do not have the station password (SOP-01).

## If everyone is slow
1. Many slow units on the same server means the server is overloaded.
2. Tell the teacher; the teacher can see the load in MultiPoint Dashboard.
3. Avoid running heavy programs at the same time (e.g. all students opening videos).

## Escalate when
1. Your unit is still slow after the teacher restarted the session - create a ticket with the unit number (medium).
2. All units on one server freeze - see SOP-05 and report as high or critical.
