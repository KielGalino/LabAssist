# SOP-08: Saving Files, USB Drives and Shared Folder

**Applies to:** Student and teacher files on the lab thin clients.
**Common phrases:** where to save, lost file, file disappeared, USB not detected, flash drive, shared folder, backup, nawala ang file ko, saan mag-save, ayaw mabasa ng USB, hindi ma-detect ang flash drive, na-delete ang file

## Where to save your work
1. Save class work in your section's shared folder: `\\MPS-1\Shared\<Section>` (e.g. `\\MPS-1\Shared\ICT-11A`).
2. Create a sub-folder named with your student ID so your files are easy to find.
3. Do NOT save on the Desktop - stations are shared, and desktop files are cleared when the session is restarted.
4. The shared folder is backed up **daily at 6:00 PM**.

## USB flash drives
1. Plug the USB drive into the thin client's front USB port.
2. Wait 10-20 seconds; it appears under "This PC" as a redirected drive.
3. If not detected, unplug it, wait 5 seconds and plug it into another port.
4. All USB drives are scanned for viruses. Infected files are blocked.

## Recovering a lost file
1. Check the shared folder and your USB drive first.
2. Files saved in the shared folder before 6:00 PM of the previous day can be restored from backup.
3. Request a restore by ticket with the file name, folder and approximate date.

## Escalate when
1. You need a file restored from backup - ticket, category Other, low or medium priority.
2. The shared folder cannot be opened by the whole class - high priority.
