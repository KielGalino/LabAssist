# SOP-05: MultiPoint Server Disconnection

**Applies to:** The 3 Windows MultiPoint Servers (MPS-1, MPS-2, MPS-3) and their thin clients.
**Common phrases:** disconnected, cannot connect to server, server down, connection lost, remote session ended, which server is my PC, naputol ang connection, nadisconnect, ayaw kumonek sa server, walang server, server offline

## Which server is my unit on?
| Server | Thin clients |
|--------|--------------|
| MPS-1  | PC-01 to PC-14 |
| MPS-2  | PC-15 to PC-28 |
| MPS-3  | PC-29 to PC-42 |

## If only your unit is disconnected
1. Check that the network cable is plugged into the thin client.
2. Restart the thin client (hold power 5 seconds, wait 10 seconds, power on).
3. Log in again - unsaved work may be lost, saved files are kept.

## If several units on the same server disconnect
1. Use the table above to find the affected server.
2. Tell the teacher; the teacher can check the server status in MultiPoint Dashboard.
3. Students on that server may move to free units on another server if the teacher allows.
4. Do not restart the server yourself - only the lab administrator restarts servers.

## Escalate when
1. A whole server (14 units) is down - **critical** ticket, category Server.
2. Units on the same server keep disconnecting repeatedly - high priority ticket.
