# SOP-11: Software Requests and Installed Software

**Applies to:** Software on the MultiPoint servers used by all thin clients.
**Common phrases:** install software, install app, need program, software request, is Python installed, Packet Tracer, VS Code, paano mag-install, pwede mag-install, pa-install ng software, wala yung app

## Installed software
1. Microsoft Office (Word, Excel, PowerPoint).
2. Cisco Packet Tracer.
3. Python 3 (with IDLE).
4. Visual Studio Code.
5. Google Chrome and Microsoft Edge.
6. 7-Zip, Adobe Acrobat Reader, Notepad++.

## Students
1. Students **cannot install** software - station accounts have no administrator rights.
2. Do not run portable or downloaded programs; this violates the lab rules (SOP-13).
3. If your class needs a program, ask your teacher to request it.

## Teachers
1. Request new software with a ticket (category **Software Request**): name, version, purpose, section and date needed.
2. Requests need **3 school days** for review, licensing check and installation.
3. Software is installed on all 3 MultiPoint servers during a maintenance window.

## Escalate when
1. An installed program does not open on any unit - ticket, category Software Request, medium.
2. A program is needed urgently for an exam - teacher creates a high priority ticket.
